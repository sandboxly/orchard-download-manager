Big downloads, fast and safe to the last byte

Orchard Download Manager splits a download into parts that load at the same time, picks up where it stopped after a broken connection, and runs your queue when it suits you. No account, no ads, no tracking.

Download Free and open source · Other platforms

Downloads that don't start over

A browser loads a file over one connection, and when that connection breaks near the end, you often start again from zero. Orchard Download Manager keeps every byte it has, retries on its own and finishes the file.

It opens up to 32 connections per file, so servers that limit each connection still fill your line.

  • Resume after a broken connection
  • Several connections per file
  • No account or sign-in
  • Nothing leaves your computer

Sorted as it lands

Each download goes to the folder for its kind, if you like: videos with videos, archives with archives. The list filters by the same kinds.

  • Video
  • Music
  • Documents
  • Archives
  • Programs
  • Images

Paste a link and go

Copy a link anywhere and the app offers to download it. The Add dialog checks the link first and shows the file's name and size, and whether it can resume.

Paste a whole page of links at once, or a pattern like lecture-[01-12].mp4 for a numbered series.

Keep the line free for everything else

Three speed modes, low, medium and high, each with its own limit. Press F7 to switch between them while you work, call or stream.

In Settings (⌘, or F9) you set how many downloads run at once, the connections per file, retries, a proxy and much more. Changes take effect at once.

What sets it apart

Parts that help each other

When one connection finishes its part, it takes over half of the biggest part still loading. No connection sits idle until the file is done.

Download on a schedule

Let the queue run at night or on the days you choose. When everything is done, the app can quit or put the computer to sleep.

Checksums built in

Paste an SHA-256, SHA-1 or MD5 sum and the file is checked when it's done. A file that doesn't match is marked as damaged.

Downloads from the browser

The browser extension hands downloads over to the app, with the sign-in they need. Right-click a link to send it, or every link on a page.

A queue you control

Choose how many downloads run at once and reorder the rest with ⌥↑ and ⌥↓. The next one starts when a slot is free.

Stays awake while it works

The computer doesn't fall asleep in the middle of a download, and goes back to its usual habits when the queue is empty.

On Windows and Linux, use Ctrl instead of ⌘.
